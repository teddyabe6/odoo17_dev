# Remote Odoo Developer Bootcamp (4 Weeks)

This repository contains my structured 4-week intensive Odoo 17 bootcamp, 
designed to prepare me for remote Odoo development roles.

## 📅 Weekly Plan
- **Week 1:** Backend Mastery (ORM, models, security, tests)
- **Week 2:** Frontend (OWL, QWeb, POS customization)
- **Week 3:** Integrations (REST, Payment, File uploads, Cron jobs)
- **Week 4:** Final Remote Project (Farmer Portal System)

## 🛠 Tech Stack
- Odoo 17 (Dockerized)
- PostgreSQL 15
- Python 3.11
- OWL (Odoo Web Library)
- REST/JSON-RPC APIs

## 📂 Structure
- `addons/` → Custom Odoo modules
- `docs/` → Documentation & learnings
- `config/` → Odoo config files
- `docker-compose.yml` → Environment setup
